# 网格策略与市场状态判断

> 状态: 想法记录 + 讨论方向, 尚未实现
> 创建: 2026-08-07
> 关联: 插针挂单策略 (独立运行), ROC动量策略 (互斥切换)

## 一、核心想法

当前项目有趋势策略 (ROC动量) 和插针策略 (抓极端波动), 但缺少震荡市策略。
**网格策略**适合填补"宽幅震荡"这个市场状态的空白。

三种策略各管一种市场状态:

| 市场状态 | 特征 | 适合策略 | 项目状态 |
|---------|------|---------|---------|
| 单边趋势 | 价格持续单向运动 | ROC动量 (趋势跟随) | ✅ v12 已实现 |
| 宽幅震荡 | 价格在区间内反复波动 | 网格交易 | ❌ 未实现 |
| 极端插针 | 瞬间暴跌/暴涨后回归 | 挂单抄底 | ❌ 调研完成, 待实现 |

## 二、如何判断"该用网格" (市场状态识别)

### 2.1 ADX (趋势强度指标) — 最核心

```
ADX < 20  → 无趋势, 震荡市 → 适合网格
ADX 20-25 → 弱趋势, 过渡区
ADX > 25  → 有趋势 → 适合趋势策略
ADX > 40  → 强趋势 → 趋势策略最优
```

ADX 专门衡量趋势强度, 不区分多空方向。ADX 持续低于 20 是切换网格的最强信号。

### 2.2 价格区间特征

- 近 N 根K线高低点范围 < 15% (价格锁在窄区间)
- 收盘价在区间内反复波动 (0.2-0.8 之间, 不贴边)
- 多次触及区间上下沿但都回落 (突破失败)

### 2.3 均线斜率趋平

- MA20 斜率绝对值 < 0.5% → 趋势停滞, 适合网格

### 2.4 布林带宽度收窄

- bandwidth < 近120根K线的 P25 分位 → 波动收敛
- 收窄后多次假突破 = 网格好时机

### 2.5 ROC 在零轴附近反复

- ROC(20) 标准差 < 2%, 均值接近 0
- 动量消失, 价格没方向 → 适合网格
- (与 ROC 动量策略完全相反的需求)

## 三、震荡市评分系统 (切换规则)

| 条件 | 满足得分 |
|------|---------|
| ADX(14) < 20 | +2 |
| ADX(14) 20-25 | +1 |
| 近20根K线振幅 < 8% | +1 |
| MA20斜率绝对值 < 0.3% | +1 |
| 布林带宽 < 近120根 P25 | +1 |
| ROC(20)绝对值 < 1% | +1 |
| 近5次触及区间沿均回落 | +1 |

```
评分 ≥ 4  → 切换网格策略
评分 2-3  → 观望/轻仓
评分 ≤ 1  → 趋势策略为主
```

## 四、网格策略参数设计 (初步)

```
网格区间: 近20根K线的 [low, high]
网格层数: 6-8 层
每层间距: (high-low) / 层数
每层仓位: 总资金的 10-15%
止盈: 每层买后涨一层就卖
止损: 跌破区间下沿 -3% 全部止损
杠杆: 2x (合约, 现货无需杠杆但不能做空)
```

## 五、三种策略配合方案

```
每根K线收盘时:
  1. 计算震荡评分
  2. 评分 ≥ 4 → 启动网格, 暂停趋势策略
  3. 评分 ≤ 1 → 启动趋势策略, 暂停网格
  4. 中间区域 → 两个策略都轻仓或观望

插针策略独立运行 (随时挂单, 不依赖状态判断)
```

## 六、待讨论问题 (下次继续)

1. **切换频率**: 多久判断一次? 1h? 4h? 太频繁会反复切换被两头打
2. **切换延迟**: 趋势转震荡不是瞬间的事, 是否需要连续 N 根K线确认?
3. **资金分配**: 两个策略同时跑还是互斥? 同时跑需要更多保证金
4. **网格参数动态调整**: 区间是固定的还是随价格移动?
5. **网格做空**: 合约可以双向网格, 现货只能单向. 是否只做多?
6. **与插针策略的关系**: 网格区间外的极端波动交给插针策略, 两者如何衔接?
7. **回撤控制**: 网格在假突破时亏损放大, 如何限制最大回撤?
