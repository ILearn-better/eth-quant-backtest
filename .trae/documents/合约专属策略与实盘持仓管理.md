### 变更 1：新建 `strategies/eth_roc_momentum_contract.py`

**目的**：合约专属策略，与现货 v12 独立，新增动量衰竭阈值 + ATR 自适应止盈止损。

**基于**：复制 `strategies/eth_roc_momentum_v12.py` 结构，做以下修改：

1. **类名**：`EthROCMomentumContract`（继承 `BaseStrategy`）
2. **name**：`"ETH双ROC动量策略-合约"`
3. **新增函数 `calc_atr(highs, lows, closes, period)`**：
   ```python
   def calc_atr(highs, lows, closes, period):
       """计算 ATR(Average True Range)
       TR = max(high-low, abs(high-prev_close), abs(low-prev_close))
       ATR = TR 的简单移动平均
       """
       n = len(closes)
       tr = np.full(n, np.nan)
       for i in range(1, n):
           tr[i] = max(highs[i]-lows[i],
                       abs(highs[i]-closes[i-1]),
                       abs(lows[i]-closes[i-1]))
       # SMA of TR
       atr = np.full(n, np.nan)
       if n >= period:
           cumsum = np.nancumsum(tr)
           atr[period:] = (cumsum[period:] - cumsum[:-period]) / period
       return atr
   ```

4. **新增参数**：`MOMENTUM_DEATH_THRESH`、`ATR_PERIOD`、`SL_ATR_MULT`、`TP_ATR_MULT`

5. **`run_backtest` 修改**：
   - 计算 `atr = calc_atr(highs, lows, closes, ATR_PERIOD)`
   - 开仓时记录 `entry_atr`、`sl_price`、`tp_price`：
     - 做多：`sl_price = entry_price - SL_ATR_MULT * entry_atr`，`tp_price = entry_price + TP_ATR_MULT * entry_atr`
     - 做空：`sl_price = entry_price + SL_ATR_MULT * entry_atr`，`tp_price = entry_price - TP_ATR_MULT * entry_atr`
   - 出场条件修改：
     - 动量衰竭：做多时 `cur_roc5 < -MOMENTUM_DEATH_THRESH`；做空时 `cur_roc5 > MOMENTUM_DEATH_THRESH`
     - 止损：`price <= sl_price`（做多）或 `price >= sl_price`（做空）
     - 止盈：`price >= tp_price`（做多）或 `price <= tp_price`（做空）— **新增，v12 无止盈**
     - 超时：`held_bars >= MAX_HOLD_BARS`
   - 交易记录新增字段：`entry_atr`、`sl_price`、`tp_price`、`exit_reason` 细化（`momentum_death`/`SL`/`TP`/`timeout`/`force_close`）

6. **保留辅助方法**：`_get_position_size`、`_open_position`（新增 sl_price/tp_price/entry_atr 字段）、`_calc_unrealized`、`_calc_pnl`

#### 2.5 新增 `_check_exit_conditions` 方法
在每根K线收盘时检查现有持仓的出场条件：
```python
def _check_exit_conditions(self, price, cur_roc5, cur_atr, bar_ts, bar_idx):
    """检查当前持仓是否触发出场, 返回 (should_close, reason, exit_price)"""
    if self.position is None:
        return False, "", 0
    pos = self.position
    direction = pos["direction"]
    held_bars = bar_idx - pos["entry_bar"]

    # 动量衰竭 (带阈值)
    if direction == "long" and cur_roc5 < -MOMENTUM_DEATH_THRESH:
        return True, "momentum_death", price
    if direction == "short" and cur_roc5 > MOMENTUM_DEATH_THRESH:
        return True, "momentum_death", price

    # 止损
    if direction == "long" and price <= pos["sl_price"]:
        return True, "SL", pos["sl_price"]
    if direction == "short" and price >= pos["sl_price"]:
        return True, "SL", pos["sl_price"]

    # 止盈
    if direction == "long" and price >= pos["tp_price"]:
        return True, "TP", pos["tp_price"]
    if direction == "short" and price <= pos["tp_price"]:
        return True, "TP", pos["tp_price"]

    # 超时
    if held_bars >= MAX_HOLD_BARS:
        return True, "timeout", price

    return False, "", 0
```

#### 2.6 新增 `_open_position` / `_close_position` 方法
```python
def _open_position(self, direction, price, ts, bar_idx, cur_roc5, cur_roc20, cur_atr):
    """开仓: 计算动态SL/TP价格, 记录持仓"""
    drawdown = (self.peak_balance - self.balance) / self.peak_balance if self.peak_balance > 0 else 0
    multiplier = self._get_position_size(drawdown)
    fraction = FRACTION_BASE * multiplier
    notional = self.balance * fraction * LEVERAGE

    if direction == "long":
        sl_price = price - SL_ATR_MULT * cur_atr
        tp_price = price + TP_ATR_MULT * cur_atr
    else:
        sl_price = price + SL_ATR_MULT * cur_atr
        tp_price = price - TP_ATR_MULT * cur_atr

    self.position = {
        "direction": direction,
        "entry_price": price,
        "size_usdt": notional,
        "fraction": fraction,
        "entry_time": ts,
        "entry_bar": bar_idx,
        "entry_roc5": round(cur_roc5, 2),
        "entry_roc20": round(cur_roc20, 2),
        "entry_atr": round(cur_atr, 2),
        "sl_price": round(sl_price, 2),
        "tp_price": round(tp_price, 2),
    }

def _close_position(self, exit_price, reason, ts, bar_idx):
    """平仓: 计算盈亏, 记录交易, 更新余额"""
    pos = self.position
    if pos["direction"] == "long":
        price_diff = exit_price - pos["entry_price"]
    else:
        price_diff = pos["entry_price"] - exit_price
    pnl_pct = price_diff / pos["entry_price"]
    raw_pnl = pnl_pct * pos["size_usdt"]
    close_fee = pos["size_usdt"] * FEE_RATE / 2
    net_pnl = raw_pnl - close_fee

    trade = {
        **pos,
        "exit_price": round(exit_price, 2),
        "pnl": round(net_pnl, 4),
        "exit_time": ts,
        "held_bars": bar_idx - pos["entry_bar"],
        "reason": reason,
    }
    self.trade_history.append(trade)
    self.trade_history = self.trade_history[-50:]
    self.balance += net_pnl
    if self.balance > self.peak_balance:
        self.peak_balance = self.balance
    self.position = None
    return trade
```

## 假设与决策

1. **跳过参数优化**：用户明确选择"策略+实盘(跳过优化)"，使用基于 v12 + 合约特性调整的经验参数，不做 OAT 扫描。
2. **ATR 自适应止盈止损**：SL = 1.5×ATR，TP = 3.0×ATR（2:1 风险回报比）。v12 原本只有固定 U 止损无止盈，合约策略新增 ATR 止盈。
3. **动量衰竭阈值**：`MOMENTUM_DEATH_THRESH=0.8`，ROC 需跌破 -0.8（做多）才出场，过滤震荡行情中的频繁出场。
4. **单仓位模型**：与 v12 一致，同一时间最多一个持仓（不做加仓/分仓）。
5. **实盘平仓触发**：K线收盘检查全部出场条件；未收盘K线仅检查 SL/TP 价格触发（价格触及立即平仓，不等收盘）。
6. **不改现货文件**：所有变更仅涉及 `strategies/eth_roc_momentum_contract.py`(新)、`live_trader_contract.py`、`main_v12_contract.py`。
7. **前端复用**：合约前端 HTML 内嵌在 `live_trader_contract.py`，与现货 `live_trader.py` 的前端独立，互不影响。
