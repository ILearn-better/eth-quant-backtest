# 策略池 Strategy Pool

本项目为 ETHUSDT 量化回测框架，包含策略实现、回测引擎、参数优化工具和数据下载工具。

---

## 项目结构

| 文件 | 职责 |
|------|------|
| `base.py` | 回测基类 (`BaseStrategy`)、统计计算 (`compute_stats`)、HTML报告生成 (`generate_html_report` + 4个图表函数) |
| `main.py` | 回测入口 (当前运行 v10) |
| `main_v11.py` | v11 策略回测入口 |
| `main_v12.py` | v12 策略回测入口 |
| `paper_trading.py` | 实盘模拟盘 (v12, WebSocket常驻, 3x杠杆, 状态持久化) |
| `paper_report.py` | 模拟盘日报生成器 (HTML报告) |
| `start_paper_trading.bat` | 模拟盘一键启动脚本 |
| `strategies/eth_rsi_leverage.py` | v8 策略 — 日线顺势, **+10.01%** |
| `strategies/eth_ma_reversion_v9.py` | v9 策略 — 1h均值回归, 当前亏损中优化 |
| `strategies/eth_dca_v10.py` | v10 策略 — 月均线DCA抄底 |
| `strategies/eth_rsi_dca_v11.py` | v11 策略 — RSI超卖定投(FIFO), 10x杠杆, **+54.25%** |
| `strategies/eth_roc_momentum_v12.py` | v12 策略 — 双ROC动量+成交量, **+140.51%** 💎 |
| `optimize.py` | v4 参数扫描工具 (旧) |
| `optimize_v12.py` | v12 参数优化工具 (网格扫描+组合验证) |
| `fetch_data.py` | 数据下载工具 |
| `data/` | K线数据目录 |

## v10 策略 — 月均线DCA分批抄底 (1h)

|------|-----|
| 文件 | `eth_dca_v10.py` |
| 类名 | `EthDCAV10` |
| 数据周期 | 小时线 1h |
| 交易对 | ETHUSDT |
| 本金 / 杠杆 | 150 USDT / **3x** |
| 均线 | MA720 (150天 × 24h = 真月均线) |

**买入规则 (月均线下方越跌越买)**:

| 档位 | 距MA720跌幅 | 仓位占比 |

| L1 | -20% | 1/5 本金 |

**回测表现 (17520根1h线)**:

| 指标 | 值 |
|------|-----|
| 总交易 | 2 笔 |
| 胜率 | 0% |
| 收益率 | **-14.78%** |
| 最大回撤 | 14.78% |

**特点**: 只做多, 不设止损(长期持有信念), 动态回撤减仓。回撤控制优于v9，但卖出条件偏早导致亏损。

## v11 策略 — RSI超卖定投 (FIFO)

| 属性 | 值 |
|------|-----|
| 文件 | `eth_rsi_dca_v11.py` |
| 类名 | `EthRsiDcaV11` |
| 数据周期 | 1h K线聚合为日线RSI(14) |
| 交易对 | ETHUSDT |
| 本金 / 杠杆 | 150 USDT / **10x** (合约) |
| 分笔数 | 100 笔 (每笔1.5 USDT保证金, 名义15 USDT) |
| 手续费 | 0.04% (Binance合约 maker/taker) |

**买卖规则**:

| 操作 | 触发条件 | 执行方式 |
|------|---------|---------|
| 买入 | 日线 RSI < 30 (超卖) | 每日最多1次, 入FIFO队列, 最多100笔 |
| 卖出 | 日线 RSI > 70 (超买) | FIFO卖出最早的一笔, 每日最多1次 |
| 清仓 | 回测截止日 | 所有剩余持仓全部平仓 |

**回测表现 (17520根1h线, 730根日线)**:

| 指标 | 值 |
|------|-----|
| 总买入次数 | 45 笔 / 100 笔上限 |
| 中途超买卖出 | 18 笔 (全部盈利!) |
| 期末清仓 | 27 笔 |
| 胜率 | **64.4%** |
| 收益率 | **+54.25%** (+81.37 USDT) |
| 最大回撤 | **17.25%** |
| 盈亏比 | — |
| Sharpe | **36.76** 💎 |
| 本金 -> 最终 | 150 -> **231.37 USDT** |

**特点**: 10x高杠杆放大收益(每笔保证金仅1.5U但名义仓位15U), RSI超卖低价区买入→超买高价区卖出获取杠杆波段利润。100笔细粒度分散风险, FIFO先买先卖锁定低价仓最大利润。最大回撤17%, 收益风险比突出。

## v12 策略 — 双ROC动量策略 (1h趋势跟踪) 🏆 当前最优

| 属性 | 值 |
|------|-----|
| 文件 | `eth_roc_momentum_v12.py` |
| 类名 | `EthROCMomentumV12` |
| 数据周期 | 小时线 1h |
| 交易对 | ETHUSDT |
| 本金 / 杠杆 | 150 USDT / 3x |
| 硬止损 | -5 USDT |
| 最大持仓 | 72根K线 (3天) |
| ROC 周期 | 短期 **8** / 中期 20 (2026-08-05参数优化) |

**入场规则 (双ROC同向 + 加速 + 放量)**:

| 方向 | 条件 |
|------|------|
| 做多 | ROC(8) > 0 且 ROC(20) > 0 且 ROC(8) > ROC(20) 且 成交量 > VolMA(20) |
| 做空 | ROC(8) < 0 且 ROC(20) < 0 且 ROC(8) < ROC(20) 且 成交量 > VolMA(20) |

**出场规则**:

| 方式 | 条件 |
|------|------|
| 动量衰竭 | 做多时 ROC(8) < 0 / 做空时 ROC(8) > 0 |
| 硬止损 | 亏损 >= 5 USDT |
| 超时 | 持仓 >= 72根K线 |

**回测表现 (17520根1h线, 优化后参数)**:

| 指标 | 值 |
|------|-----|
| 总交易 | 756 笔 |
| 胜率 | 36.4% |
| 收益率 | **+140.51%** |
| 最大回撤 | 25.70% |
| Sharpe | 6.20 |
| 盈亏比 | 1.26 |
| 本金 -> 最终 | 150 -> 360.77 USDT |

**分方向统计**:

| 方向 | 笔数 | PnL |
|------|------|-----|
| 做多 | 359 笔 | +179.94 |
| 做空 | 397 笔 | +30.83 |

**参数优化记录 (2026-08-05)**:

| 参数 | 默认 | 最优 | 说明 |
|------|:---:|:---:|------|
| ROC_SHORT | 5 | **8** | 减少噪音信号 |
| SL_USDT | 3 | **5** | 放宽止损减少被扫 |

- 单参数扫描: ROC8(+120%) / SL5(+93%) / 杠杆7x(+133%但回撤40%过激)
- **样本外验证 (2026-01~05, 未参与优化)**: 保守组合收益+39.38%, 回撤仅5.95%, 优于默认(+41.04%/9.71%回撤) → **非过拟合**
- 杠杆保持3x (7x虽收益更高但回撤40%, 不适合模拟盘)
- 优化工具: `optimize_v12.py` (支持 --quick 快速模式)

**特点**: 首次同时捕捉"涨速"和"跌速"的策略。做多+做空双方向盈利，动量衰竭出场贡献绝大部分利润。

## 已知问题与优化方向

1. **v9做空严重拖累**: 做空亏损 -46.42U，考虑只做多方向
2. **RSI<30在1h触发太频繁**: 86笔多单中大量噪音信号，可收紧阈值至RSI<25或增加确认条件
3. **仓位4/5太激进**: `FRACTION_BASE=0.8` 风险敞口过大，可降低到0.4(2/5)或0.2(1/5)
4. **optimize.py为v4旧版**: v12参数优化请使用 `optimize_v12.py` (README已知问题已通过新建工具解决)

## 使用说明

```bash
# 运行 v10 策略 (月均线DCA抄底)
python main.py

# 运行 v11 策略 (RSI超卖定投)
python main_v11.py

# 运行 v12 策略 (双ROC动量)
python main_v12.py

# 实盘模拟盘 (v12, WebSocket常驻监听, 状态自动保存)
python paper_trading.py
# 或双击 start_paper_trading.bat

# 模拟盘日报 (读取paper_state生成HTML报告)
python paper_report.py
python paper_report.py --days 7   # 汇总最近7天

# v12 参数优化 (网格扫描 + 样本外验证)
python optimize_v12.py
python optimize_v12.py --quick   # 快速模式

# 参数扫描优化 (v4旧工具)
python optimize.py

# 下载K线数据
python fetch_data.py

# 输出:
#   reports/backtest_ETHUSDT_1h_<timestamp>.html  (完整HTML报告)
#   reports/charts/*_equity.png                    (资金曲线图)
#   reports/charts/*_drawdown.png                  (回撤曲线图)
#   reports/charts/*_pnl.png                       (盈亏分布图)
```
